# Skills independientes

Copiá acá skills que no pertenecen a vstack ni a una especialidad, por ejemplo `skills/ponytail/SKILL.md`. Conservá sus referencias y scripts. No viene incluida ponytail: esta carpeta está preparada para agregarla.

El nombre de la carpeta debe coincidir con `name` y ser único en toda la colección. Ejecutá `kix sync` para enlazarlas en Claude y Codex. `kix list` las muestra como `independent`.

Una skill sigue siendo una skill aunque se invoque con `/nombre`. No necesita además un archivo de commands.
